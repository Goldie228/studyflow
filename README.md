# StudyFlow — веб-версия приложения

Адаптивный веб-сайт учебного проекта **StudyFlow** — приложения для планирования
учебных сессий, работы с флеш-картами и отслеживания прогресса.

Сайт является веб-версией нативного Android-приложения (Kotlin + Jetpack Compose)
и повторяет его интерфейс: те же экраны, цвета и компоновка. Мобильная версия
сайта полностью соответствует нативному приложению.

## Возможности

- Экран загрузки (splash) и онбординг из трёх слайдов
- Авторизация: вход и регистрация
- Главный экран: приветствие, статистика, ближайшие сессии, продолжение обучения
- Сессии: список с фильтрами по дням
- Флеш-карты: колоды с прогрессом изучения
- Профиль: настройки (тёмная тема, уведомления) и статистика
- Адаптивная вёрстка: мобильная версия (нижняя навигация) и десктопная (боковое меню)

## Технологии

- HTML5 (семантическая разметка)
- CSS3 (Flexbox, Grid, CSS-переменные, media queries)
- JavaScript (переключение экранов, вкладки, тумблеры)
- Шрифт Inter (Google Fonts)

Без сборки и фреймворков — только статические файлы.

## Структура проекта

```
studyflow/
├── index.html      # разметка всех экранов
├── styles.css      # стили и адаптивность
├── app.js          # логика навигации и интерактива
├── preview.png     # скриншот мобильной версии
└── assets/         # изображения и логотипы
```

## Локальный запуск

Откройте `index.html` в браузере или поднимите простой сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```
